# Configuration examples

These small reference files contain fictional examples, not saved operator state.
The hub writes active state beneath `DATA_DIR` (see
[Configuration](../docs/CONFIGURATION.md)); these repository files are excluded
from the Docker image. Create profiles and macros through the UI, or adapt these
schemas for a disposable development data directory. `scenes.json` illustrates
the legacy routing format retained for compatibility and migration testing.

Physical CEC behavior depends on the connected TV/source and requires observation.
